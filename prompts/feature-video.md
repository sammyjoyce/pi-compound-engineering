# feature-video (pi)

## Context

$ARGUMENTS

If empty, ask what feature/change needs a walkthrough.

## Workflow

1. Identify the 3-5 key moments to show.
2. Draft a 30-90 second script:
   - starting state
   - action
   - result
3. Suggest capture options:
   - macOS: QuickTime / Screenshot toolbar
   - Linux: OBS / wf-recorder
   - Windows: Xbox Game Bar
4. Suggest what to include in PR notes:
   - link to video
   - steps demonstrated
   - any edge cases not covered

Do not attempt to upload unless the user provides a preferred destination/tool.
